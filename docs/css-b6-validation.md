# P0.1-B6 — final validation

Run from the B6 branch, on one machine, with a clean checkout, Node/npm, the existing Playwright Chromium installation and Pillow. Install Pillow in the existing Python virtual environment if missing. Run `python tests/css-b6.py`. Six isolated detached worktrees are created and removed; evidence stays in ignored tests/artifacts/b6. Each run uses npm ci, lint, bundle, npm test and the existing coverage harness (three browser suites). Baseline and B5 are each repeated to detect unstable screenshots. No tolerance is silently applied; pixel masks include alpha differences. Missing captures and size changes fail. Do not interpret an unstable self-comparison as a CSS regression. Preserve evidence before rerunning; --reuse only compares saved evidence.

Inspect summary.json, visual.json, diffs/, b2-observed-delta.json, final-observed-delta.json, residual.csv and residual.json. The residual tags are heuristic and overlap; all entries are retained pending manual review. Source cascade audit: run node tests/css-b6-cascade.mjs. It compares the baseline and B5 source AST after removing only the explicitly listed obsolete selector branches; compares declaration order, layer/media ancestry, rule order and the historical :is specificity. The B3 impossible branch is accepted only at the documented lunar group. The gate is source-level; compiled/runtime equivalence requires visual evidence and review of compiled signature changes.

Do not merge until the source audit, local browser suites, visual repeatability and before/after comparison pass, all residuals are reviewed, B2 is explained, CI is green and Android physical verification is recorded.
