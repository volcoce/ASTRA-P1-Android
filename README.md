# ASTRA P1 Android

Application personnelle de suivi astrologique tropical et sidéral (Lahiri), avec calendrier, transits et journal local.

**État** : projet Android 17 (API 37) en développement, avec ressources astronomiques précalculées pour 2026–2028. L'APK P1 n'a pas encore été compilé ni testé sur téléphone.

Les données natales et les éphémérides sont personnelles ; conserver ce dépôt privé.
